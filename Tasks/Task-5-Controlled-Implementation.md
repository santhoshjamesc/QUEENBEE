# Task 5: Controlled Implementation (Stage 4)

**Objective:** Build only the approved milestones, in the approved order.

## Work
- Implement milestone by milestone (shell and first real session, multi-session, Queen approval gate, task engine and broker, watchdog, skills, code intelligence, office).
- Monitor and verify each milestone.

## Rules
- No unrequested features.
- Follow existing conventions.
- Stop and report on any deviation (spec §2.4).

## Done when
Each milestone is verified against its acceptance criteria.

## Gate
User sign-off per milestone.
