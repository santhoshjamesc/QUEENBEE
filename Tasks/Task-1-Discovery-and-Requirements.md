# Task 1: Discovery and Requirements Clarification (Stage 1)

**Objective:** Understand the current state and get the user's answers to open questions.

## Work
- Inspect the repo (greenfield: only Task.md exists).
- Compare the current state with the spec.
- List gaps, ambiguities and technical constraints.
- Ask the clarification questions (technology, auth, approvals, concurrency, milestone order, languages, office style).
- Document the answers as requirements.

## Constraint
Do not modify code.

## Done when
The user has answered the questions and the requirements are recorded.

## Gate
User confirms the requirements.
